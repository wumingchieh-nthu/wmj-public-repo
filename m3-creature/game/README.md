# 《Speech Bubbles》第一章 · 初芽　網頁版

**直接在瀏覽器裡玩：** https://wumingchieh-nthu.github.io/wmj-public-repo/m3-creature/game/

- 建議用電腦版 Chrome 或 Edge，第一次開啟要下載約 60 MB，請稍等一下。
- 開始遊戲後**點一下畫面**，就能用滑鼠轉動視角。
- 暫停：按 **P**（網頁版的 Esc 會先被瀏覽器拿去解除滑鼠鎖定，遊戲也會自動暫停）。
- 存檔存在這個瀏覽器裡；換瀏覽器或清除網站資料就會不見。
- 網頁版畫面比 Windows 版簡化（例如湧浪的泥沙牆改用較簡單的做法），完整畫質請玩 Windows 版（見上一層的「遊戲檔下載網址」）。

## 操作

| 按鍵 | 澤水花（幼體） | 澤蜃（成體） |
|---|---|---|
| W A S D | 游動 | 行走 |
| 滑鼠 | 轉動視角 | 轉動視角 |
| Space ／ Shift | 上浮 ／ 下潛 | （Shift）潛進沙裡 |
| 1 2 3 | 低頻 ／ 中頻 ／ 高頻聲波 | 1 低頻、2 震動 |
| P | 暫停 | 暫停 |
| R | 重來這一區 | 重來這一區 |
